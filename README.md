# Star Wars theme

A Claude desktop mod with a light Tatooine theme (sand, Jedi blue) and a dark Death Star theme (steel, Sith red). It follows your system light/dark setting.

It also adds:

- A backdrop: twin suns over dunes in light mode, a starfield and a distant Death Star in dark mode (desktop app only).
- Star Wars spinner words while Claude thinks or works. These show in the desktop app, the terminal CLI and VS Code.
- A greeting line at session start, and a toast like "Made the jump to lightspeed" when a long turn finishes.

## Install

At the prompt of a terminal session:

```
/plugin install star-wars-theme --marketplace gorassss/star-wars-theme
```

From a shell:

```
claude plugin install star-wars-theme --marketplace gorassss/star-wars-theme
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `gorassss/star-wars-theme`, then Add plugin.

Colors and the backdrop draw in the desktop app only. The terminal and VS Code get the spinner words.
